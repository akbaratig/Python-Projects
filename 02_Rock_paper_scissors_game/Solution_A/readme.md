# ✂️ Rock Paper Scissors Game

A classic CLI-based Rock, Paper, Scissors game written in Python. Play a 10-round match against the computer with automated score tracking and input validation.

---

## 📌 Features

* 🎮 **10-Round Gameplay:** Plays a full 10-round match between the user and the computer.
* 🛡️ **Input Validation:** Ensures the player enters a valid action (`rock`, `paper`, or `scissors`) before proceeding.
* 🤖 **Random Computer Moves:** Uses Python's `random` module to select the computer's choice.
* 📊 **Score Tracking:** Tracks player wins, system wins, and tie rounds, displaying final statistics at the end.

---

## 🛠️ Requirements & Tech Stack

* **Language:** Python 3.x
* **Modules:** `random` (Standard Built-in Library)

   ```bash
   git clone https://github.com/akbaratig/Python-Projects.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd Python-Projects/Projects/"Rock Paper Scissors"
   ```

3. **Run the game:**
   ```bash
   python main.py
   ```

---

## 🎮 How to Play

1. Choose your action when prompted: `rock`, `paper`, or `scissors`.
2. The computer will randomly pick its choice.
3. The winner of each round will be printed immediately.
4. After 10 rounds, the total scores and final match result will be displayed.
