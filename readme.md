## 📌 About This Repository

This repository serves as a central hub for my Python projects. Each project lives in its own folder and can be run independently, without relying on any other project in the repo.

The goals of this repository are to:

- 💪 Practice consistently and improve programming skills
- 🧩 Learn principles of clean, modular, and well-structured code
- 📂 Keep an organized archive of personal projects
- 🎓 Showcase progress and growth over time

---

## 📁 Project Structure

Each project has its own folder with a dedicated `README.md` that covers its features, how to run it, and how to use/play it. The overall layout looks like this:

```
python-projects/
│
├── project-name-1/
│   ├── README.md
│   ├── main.py
│   └── ...
│
├── project-name-2/
│   ├── README.md
│   └── ...
│
└── README.md   <- you are here
```

> 💡 As new projects are added, each one gets its own folder with its own `README.md`.

## 🛠️ Requirements

- **Language:** Python 3.8 or higher
- **Package manager:** pip
- Any project-specific dependencies are listed in that project's own `README.md`.

Check your installed Python version:

```bash
python --version
```

## 📥 Installation

1. Clone the repository:

```bash
git clone https://github.com/<your-username>/python-projects.git
```

2. Move into the repository folder:

```bash
cd python-projects
```

3. (Optional but recommended) Create a virtual environment:

```bash
python -m venv venv
source venv/bin/activate      # On Windows: venv\Scripts\activate
```

---

## ▶️ Running a Project

Each project runs independently. Just move into that project's folder and run its main file:

```bash
cd project-name
python main.py
python src/main.py
```

More detailed instructions (features, project-specific requirements, how to play/use it) are available in that project's own `README.md`.
