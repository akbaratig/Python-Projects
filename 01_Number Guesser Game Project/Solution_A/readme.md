# 🎯 Number Guessing Game

A fun and interactive CLI-based Number Guessing Game built with Python. Test your luck and logic by guessing the secret number generated by the computer!

---

## 📌 Features

* 🎲 **Random Number Generation:** Generates a random integer between **1 and 100** for every game.
* 🛡️ **Input Validation:** Handles invalid inputs (non-numeric characters) and out-of-range numbers gracefully without crashing.
* 🏆 **Dynamic Scoring System:** Starts with **100 points** and deducts **5 points** for each incorrect guess (minimum score is 0).
* 🚪 **Easy Exit:** Allows players to quit anytime by typing `'q'`.

---

## 🛠️ Requirements & Tech Stack

* **Language:** Python 3.x
* **Modules:** `random` (Standard Built-in Library)

---

## 🚀 How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/akbar/python-projects.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd python-projects/number_guessing_game
   ```

3. **Run the game:**
   ```bash
   python main.py
   ```

---

## 🎮 How to Play

1. Run the script and type a number between **1 and 100**.
2. The program will give you feedback:
   * **"Your Guess is too high"** 📈
   * **"Your Guess is too low"** 📉
3. Keep guessing until you land on the correct number to win!
4. Type **`q`** at any prompt if you want to quit the game early.
