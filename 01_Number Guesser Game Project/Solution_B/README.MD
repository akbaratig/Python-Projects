# 🎯 Number Guessing Game

A fun and interactive CLI-based Number Guessing Game built with Python. Test your luck and logic by guessing the secret number generated by the computer!

---

## 📌 Features

* 🎲 **Random Number Generation:** Generates a random integer between **1 and 100** for every game.
* 🛡️ **Input Validation:** A dedicated validator handles invalid or out-of-range inputs gracefully without crashing.
* 💡 **Smart Hints:** Provides a hint after every incorrect guess to help you get closer to the answer.
* 🏆 **Scoring System:** Starts with a base score and deducts a point for each incorrect guess.
* 🔄 **Replay Option:** Lets you play another round right after finishing one, without restarting the program.

---

## 🛠️ Requirements & Tech Stack

* **Language:** Python 3.x
* **Modules:** Standard Library only — no external dependencies required

---

## 🎮 How to Play

1. Run the script and type a number between **1 and 100** when prompted.
2. If your guess is wrong, you'll receive a hint to help narrow down the answer.
3. Keep guessing — each wrong guess lowers your score a bit.
4. Once you guess correctly, your final score is displayed.
5. Type **`Y`** to play another round, or **`N`** to exit the game.
